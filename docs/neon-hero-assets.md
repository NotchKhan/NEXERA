# NEXERA hero artwork

Built-in imagegen mode. Source design: user-provided dark five-card NEXERA reference. Only the decorative wallpaper inside each card was generated; typography, icons, borders, grid, perspective and interaction are implemented in React/CSS/SVG. Output artwork is an approximation of the reference, not a claim of pixel-identical source art. Supplied originals can replace each WebP without changing the components.

Optimized with Sharp to 800 × 1000 WebP, quality 88. Combined size: 116,160 bytes. The image filenames below are relative to the repository root.

## violet

Saved asset: `public/hero-violet.webp`.

Prompt: Use case: precise-object-edit. Input image is design reference. Create ONLY the flat, straight-on full-bleed decorative wallpaper INSIDE the far LEFT PURPLE WhatsApp card from the reference, matching its existing abstract 3D folded-wave shapes, color distribution, glossy materials and light as closely as possible. Electric violet and rich dark purple. Bottom quarter has two plump broad satin folds: a violet low arc in foreground and a brighter pink-violet raised lobe behind at the right edge. Upper half dark violet with magenta upper rim lighting. Output portrait 4:5 rectangular wallpaper filling entire image edge to edge. Remove ALL words, lettering, symbols, logos, icons, buttons, arrows, borders and rounded frame. Do NOT reproduce the whole website or other cards. The upper 42% should remain relatively simple smoothly lit dark gradient for later HTML text overlay. Render the waves like the reference: broad clean luminous surfaces, dimensional subtle shadows, thin glossy bright rims, sophisticated smooth 3D satin/glass, not thin wire lines. Keep the design faithful; no extra objects, sparkles, or grain. No perspective tilt: front-facing flat wallpaper. This asset will be used ONLY as decorative background below real HTML text and controls.
